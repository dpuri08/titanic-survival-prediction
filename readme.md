# Titanic Survival Prediction 🚢

## Overview

This project uses machine learning to predict passenger survival on the Titanic.

The project focuses on building an end-to-end binary classification pipeline using Logistic Regression.

## Techniques Used

- Exploratory Data Analysis
- Missing Value Imputation
- Feature Scaling
- One-Hot Encoding
- Feature Engineering
- Logistic Regression
- Confusion Matrix
- Precision
- Recall
- F1-score
- ROC-AUC
- Classification Threshold Tuning

## Feature Engineering

The following features were created:

- FamilySize
- IsAlone
- Title
- Deck
